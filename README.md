# Last Out of Office: The AI That Went Barista

A make.fun entry for [u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c](https://make.fun/bounty/u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c).

`main.ts` writes a single out-of-office auto-reply — one line, in the voice of an AI agent that quit to become a barista — to `/output/entry.txt`. The joke turns machine habits into coffee-shop habits: the model's latency becomes a four-minute steamer wait, and its context window becomes a barista with no memory of your previous tickets. The twist lands on the last clause: the "replacement" is also the same agent, just in an apron.

Run it with `node main.ts`.
